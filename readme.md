Перед тем, как запустить, нужно установить Python ~3.14.10 (или выше. На версии `3.14.10` всё работает) с официального сайта

Как запустить:

1. Скачать репозиторий
2. Распаковать в любом месте
3. Извлечь ffmpeg.exe из ffmpeg.7z в корень распакованного репозитория
4. Запустить install.bat
5. Запустить run.bat
6. Если браузер не открылся, то нужно будет открыть браузер и перейти на страницу `http://127.0.0.1:5000`
